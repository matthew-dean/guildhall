# Internal Constitutions

This directory holds internal governance documents for Guildhall architecture,
runtime behavior, and product surfaces. A constitution is stronger than an audit:
it names the rule future work must obey, the limited exceptions, and the checks
that should keep the rule from becoming aspirational prose.

Constitutions are not public product docs. Public documentation can explain the
resulting behavior, but the operating law for agents and implementation plans
belongs here unless a future release deliberately promotes it.
