# Active Plans

The active project-state plan is:

- [`2026-07-14-project-state-architecture-pivot.md`](./2026-07-14-project-state-architecture-pivot.md)

It is the only current source of truth for project orientation, scope, release
membership, task hierarchy, execution state, and projections. Git integration,
verification, and finished-work history are detail facts over that model; the
retired user-facing `Closure` concept is not part of the current vocabulary.
Older release-era and implementation plans live in
[`archive/`](./archive/README.md). They are retained for historical evidence,
but they are not active instructions or parallel architecture proposals.

New work should update the active pivot or create a clearly owned independent
spec. It should not revive an archived plan as a second backlog.
