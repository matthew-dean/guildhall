# Guide

Guildhall is easiest to learn as a product journey:

1. open the local service
2. connect one project
3. give that project a small set of clear tasks
4. watch the guild work, ask, review, and stop with receipts

If you are new to AI coding tools, start here. The first pages avoid the
internal machinery and focus on what you need to do next.
