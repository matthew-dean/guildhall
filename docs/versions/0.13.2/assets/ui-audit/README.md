# UI Screenshot Evidence

The screenshots in `0-10-0/` are historical Guildhall 0.10.0 interface
captures. They illustrate the older project shell and are not evidence for the
published 0.11.0 or 0.12.0 releases.

The 0.11.0 and 0.12.0 release claims require fresh captures from the installed
app, with the route, viewport, capture date, and state represented in the
filename or accompanying audit. The internal June 2026 project-orientation
captures remain useful investigation evidence, but they should not be reused
as current release screenshots without a fresh route check.
