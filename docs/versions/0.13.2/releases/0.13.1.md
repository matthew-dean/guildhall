# Guildhall 0.13.1

Guildhall `0.13.1` is the flow-hardening patch for the 0.13 release line.

## What changed

- **Shipped means done:** a shipped release shows a compact receipt and cannot
  regain stale migration, approval, provider, pause, or repository urgency.
- **One next action:** the runtime computes the primary project action once;
  Overview and the shell render that result instead of independently ranking
  competing suggestions.
- **Recoverable refreshes:** a temporary project or Thread refresh failure
  keeps the last known state visible and offers an explicit retry.
- **Safer review controls:** spec approval is available only while the task is
  actually waiting for spec review.
- **Short task references:** project-local task keys replace long generated
  identifiers in owner-facing descriptions and links.
- **Calmer history:** Timeline is newest first, older activity loads in place,
  and completed release work stays behind an explicit disclosure.
- **Tag-safe publishing:** an interrupted release can resume only when the
  existing release tag points at the current checkout, so npm and GitHub
  artifacts cannot be built from different source trees.
