# Guildhall 0.11.0

Guildhall 0.11.0 was a hardening release for project orientation, workspace
import, and release readiness.

## Correction

An earlier description of 0.11.0 accidentally included work that was not in
the published package: the unified project-state model, compact read
projections, the optional release lifecycle, and the complete Narrative
Harness release-cycle proof. Those changes belong to 0.12.0. This note is the
correction; it does not change the already-published 0.11.0 package.

## What shipped

- **Project orientation and readiness:** Overview and Map gained clearer
  project context, current-scope summaries, release-readiness signals, and
  next-action state.
- **Semantic workspace import:** planning documents are shaped into scoped
  work instead of treating every planning bullet as an independent task;
  later-scope work remains distinguishable from the active scope.
- **Release-boundary hardening:** release and current-work readiness use the
  same release type contracts and expose clearer included, deferred, and
  blocked work.
- **Release gates:** type contracts, workspace-import behavior, runtime
  endpoints, and the release package checks were tightened before the tag.

## What it did not include

0.11.0 did not yet provide the unified persisted project-state boundary,
bounded fleet/detail projections, bounded process history, or the complete
Narrative Harness release proof. Those are the focus of 0.12.0.
