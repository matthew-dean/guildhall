# Releases

GuildHall release notes capture the product claim each version can honestly make, the proof behind that claim, and the limits that still remain.

The published docs site tracks the current public release from `main`. Older
release notes stay here, but Guildhall does not yet publish separate
version-pinned docs sites for every historical release.

- [0.6.0](./0.6.0) — bounded recovery, scoped learning, project playbooks, product feedback drafts, and model bakeoff evidence.
- [0.5.1](./0.5.1) — focused CLI surface, clearer first-run docs, and route-contract cleanup after the 0.5.0 service pivot.
- [0.5.0](./0.5.0) — the service-over-projects pivot, packaged install path, and preserved narrow automation lane.
- [0.4.0](./0.4.0) — the first release with real end-to-end proof for a bounded autonomous task lane.
